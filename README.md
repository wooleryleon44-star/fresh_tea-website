# 🧊 FreshTea Ice Tea Website

Willkommen bei der offiziellen FreshTea Ice Tea Landingpage.

## 📋 Über das Projekt

Diese Website wurde erstellt, um den FreshTea Ice Tea zu präsentieren. Sie enthält:

- Moderne Startseite
- Produktvorstellung
- Sponsor-Button
- Responsives Design für Mobilgeräte und Desktop

## 🚀 Installation

1. Repository herunterladen oder klonen:
   ```bash
   git clone https://github.com/DEIN-NAME/freshtea-website.git
   ```

2. Projektordner öffnen.

3. `index.html` im Browser öffnen.

## 📁 Projektstruktur

```text
freshtea-website/
│
├── index.html
├── README.md
└── assets/
    └── images/
```

## 🌐 Online veröffentlichen

Die Website kann kostenlos mit GitHub Pages veröffentlicht werden.

1. Repository auf GitHub erstellen.
2. Dateien hochladen.
3. Unter Settings → Pages GitHub Pages aktivieren.
4. Die Website ist anschließend online erreichbar.
